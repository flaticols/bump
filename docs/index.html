semtag

Semantic versioning for Git, done right.

A minimal CLI tool that bumps semver tags, detects API changes, and supports multi-module Go repositories. Built with Go stdlib and zero bloat.

$ semtag
● on default branch (main)
● no uncommitted changes
● no remote changes
● no unpushed changes
● no new remote tags
● bump tag v1.2.3 => v1.2.4
● tag v1.2.4 created
● tag v1.2.4 pushed

Install

Homebrew

brew install flaticols/apps/semtag

Go

go install github.com/flaticols/bump@latest

Binary

Download from GitHub Releases

Usage

semtag Patch bump 1.2.3 → 1.2.4
semtag major Major bump 1.2.3 → 2.0.0
semtag minor Minor bump 1.2.3 → 1.3.0
semtag minor pkg/semver Multi-module bump pkg/semver/v1.0.0 → pkg/semver/v1.1.0
semtag undo Remove latest tag Interactive confirmation
semtag diff v1.0.0 API diff vs HEAD Suggests major/minor/patch

Flags

-r, --repoRepository path
--prefixTag prefix for multi-module
-l, --localSkip remote operations
-b, --braveSkip checks and confirmations
--no-colorDisable colors
--no-ttyDisable interactive prompts
--jsonJSON output to stdout
--verboseDebug output

Features

Minimal

Built on Go stdlib with slog, flag, and os/exec. No cobra, no framework bloat.

Multi-Module

Native support for Go multi-module repos with prefix tags like pkg/semver/v1.2.3.

API Diff

Compare Go API surfaces between versions. Suggests major/minor/patch based on breaking changes.

Safe Worktrees

API diffs run in temporary git worktrees. Your working directory is never touched.

Structured Logging

Powered by slog with a custom handler. Styled terminal output + JSON for CI/scripts.

TTY Aware

Auto-detects terminal capabilities. Colors, spinners, and prompts adapt or degrade gracefully.

Pre-flight Checks

Validates branch, uncommitted changes, remote sync, and unfetched tags before any operation.

Brave Mode

Skip all checks and prompts for CI/automation with a single --brave flag.

API Diff

$ semtag diff v0.0.6 v0.0.7
● comparing API: v0.0.6 -> v0.0.7

github.com/flaticols/bump/semver
  Incompatible changes:
    - removed: ParseStrict
  Compatible changes:
    + added: ExpandPartialVersion
    + added: ParseConstraintSet

● summary: 1 breaking, 2 compatible
● suggested bump: major
